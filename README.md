Data Science student at UCA Rosario (Argentina), focused on applied machine learning and time series. ## 🚀 Projects

A selection of my work. Full repo list on my [GitHub profile](https://github.com/choco721?tab=repositories).

📈 **[TP-SeriesTiempo-RPM](https://github.com/choco721/TP-SeriesTiempo-RPM)**
Time series analysis and forecasting of U.S. air passenger traffic (RPM, 2002-2019). ARIMA/SARIMA/REGARMA modeling and ARCH/GARCH/EGARCH volatility. Final course project. `Python` `statsmodels` `Time Series`

🛢️ **[wti-crude-oil-time-series-analysis](https://github.com/choco721/wti-crude-oil-time-series-analysis)**
Exploratory time series analysis of WTI crude oil prices (1986-present). ADF test, ACF/PACF, classical decomposition and Holt-Winters smoothing. `Python` `Time Series` `EDA`

🔥 **[PatagonIA](https://github.com/choco721/PatagonIA)**
Wildfire risk prediction in Argentine Patagonia using machine learning. Web scraping → feature engineering → classification models. `Python` `scikit-learn` `ML`

🎲 **[Pseudorandom-generators-from-scratch](https://github.com/choco721/Pseudorandom-generators-from-scratch)**
Implementation of pseudorandom number generators (LCG, Mid-Square) and statistical randomness tests from scratch, applied to probability distributions and Monte Carlo simulation. `Python` `Monte Carlo`

🔗 **[PageRank-y-Cadenas-de-Markov](https://github.com/choco721/PageRank-y-Cadenas-de-Markov)**
Critical node identification in infrastructure networks using PageRank and Markov chains. `MATLAB` `Numerical Methods`
